Problema 1: Clasificador de temperatura

Para este problema usé un ciclo "for" contando desde el -30 al 50, como indicaba elenunciado. Dentro del ciclo usé las condiciones "if" y "elif" para que revisara cada número y que dependiendo de cual sea imprima "muy frío" o "templado". Usé "else" para que el resto lo marcara como caluroso.

Problema 2: N° especiales del robot

En este problema también usé ciclo "for" para contar deñl 1 al 100. Usé el símbolo % para saber qué números eran divisibles por 5/10. Cuando se puede dividir por 5 imprime "Bip", si además es divisible por 10, se imprime "Bip Bip"

Problema 3: Detector de puntaje gamer

En este problema usé la función "input" dentro de la función "int". En el primero se guarda como texto normal, por lo que usé la segunda función y que no marcara error.

Problema 4: Perfil musical

Para este último problema se pregunta la edad de manera inicial. Luego para las preguntas de si/no usé un ".lower" al final de cada línea. Para que funcionara todo usé "and" cuando se tenían que cumplir ambas condiciones y "not" cuando cumple con una pero con la otra no.
